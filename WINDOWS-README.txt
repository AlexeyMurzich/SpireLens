SpireLens 1.1.0 — приложение для Windows 11 x64

УСТАНОВКА
Запустите SpireLens-1.1.0-Windows-x64-Setup.exe и следуйте мастеру.
Приложение устанавливается для текущего пользователя без прав администратора.
Python, браузер и интернет для работы не нужны.
После установки запускайте SpireLens через меню «Пуск».
Удаление: Параметры Windows → Приложения → Установленные приложения → SpireLens.

ПЕРЕНОСНАЯ ВЕРСИЯ
Распакуйте весь ZIP-архив в отдельную папку и запустите SpireLens.exe.
Папка _internal обязательна: нельзя переносить только EXE.

ДАННЫЕ НА ДРУГОМ КОМПЬЮТЕРЕ
Приложение ищет историю текущего пользователя в:
%APPDATA%\SlayTheSpire2\steam\<SteamID>\profileN\saves\history
Если история не найдена, нажмите «Папка сохранений» и выберите SlayTheSpire2,
папку Steam-профиля или history с файлами *.run.
Для кооператива путь должен содержать SteamID владельца профиля.
Русские названия читаются из установленной игры. При необходимости нажмите
«Файл игры / названия» и выберите SlayTheSpire2.pck.
Если игры нет, можно анализировать скопированную историю; неизвестные названия
будут показаны по внутренним идентификаторам.

ИСПОЛЬЗОВАНИЕ
История: двойной щелчок по забегу открывает разбор, колоду и маршрут.
В маршруте двойной щелчок по этажу открывает все его решения.
Заголовки таблиц меняют сортировку. Экспорт CSV находится во вкладке «История».
Новые завершённые забеги появляются автоматически каждые 15 секунд.
Настройки хранятся отдельно: %LOCALAPPDATA%\SpireLens\settings.json.
Чтобы сбросить выбранные папки, закройте приложение и удалите этот файл.

ПРИМЕЧАНИЯ К СТАТИСТИКЕ
Победы считаются по win=true. Все забеги выборки, включая прерванные,
входят в знаменатель процента побед. При необходимости выберите
«Победы и поражения (*)». Звёздочка — предположение о поражении по нулевому HP,
когда игра одновременно записала флаг прерывания; перезапуски у Неоу исключены.
Подробные определения доступны во вкладке «Источники».
Зависимость побед от выбора карты не является доказательством её силы.
Приложение не записывает в сохранения игры и не отправляет данные в интернет.

Сборка не подписана коммерческим сертификатом издателя.
Сборка предназначена для Windows 11 x64; также поддерживается Windows 10 22H2.
Запуск проверен в доступной Windows-среде. Чистая Windows 11 отдельно не проверялась.
Отдельная сборка ARM64 не создана.
